# REPLICATION.md — Paper Figure/Table → Code Map

This file maps every figure and table in the JREE submission ("An Applied Researchers' Guide to Estimating Effects from Blocked Cluster Randomized Trials: Estimands, Estimators, and Estimates," Miratrix, Weiss, Litschwartz, Hill, & Warner) — main text plus Online Appendices A–D — to the exact script or R Markdown chunk in this repository that produces it. Line numbers are approximate section/chunk anchors, not exact single lines.

Note that **Appendix D (Technical Supplement)** is pure mathematical derivation plus package-usage notes for the companion `clusterRCT` package; it has no simulation- or data-derived figures/tables and therefore no entry below.

## Main Text

| Item | Description | Producing code |
|------|-------------|----------------|
| Table 1 (p. 13) | Estimator names, notation, weighting, target estimand | Static/hand-authored, reflecting the `clusterRCT` package's estimator definitions — not generated by a script in this repo. |
| Table 2 (p. 32) | Implied cluster-/block-level weights per estimator | Static/hand-authored (derived analytically from Table 1's estimator definitions), not code-generated. |
| Table 3 (pp. 37–38) | Descriptive stats (N persons, J clusters, K blocks) for 26 studies / 29 interventions | Hand authored, but the values can be validated using the output of `empirical/make_study_flashcards.Rmd`, which reads in the statistics generated by the master analysis files. |
| Figures 1–4 (pp. 39–43) | Range of ATE estimates (Fig. 1–2) and SE ratio (Fig. 3–4), across vs. within estimand, for 50 outcomes | `empirical/final_paper_figures.R`, lines ~54–149 (chunks literally titled `## Figure 1:` … `## Figure 4:`). |

Both `final_paper_figures.R` and the underlying data it reads ultimately depend on `empirical/master_analyze_all_data.R` (requires secure-server access) or the committed `empirical/results/*.RDS` files (no server access needed — see `empirical/README.md`).

## Appendix A — Studies

18 detailed per-study description blocks (Program / Target Pop. / Study Design / Outcomes / Size / Report). **Largely hand-authored**: the narrative text (program descriptions, study-design prose, citations) is not generated by any script. The numeric "Size" fields (individuals/clusters/blocks) can be cross-checked against `empirical/results/study_descriptions.csv` (built by `empirical/load_and_prep_empirical_results.R`, lines ~68–95) or `empirical/tables/excel_supp.xlsx` (built by `empirical/excel_supp.R`), but there is no single script that renders Appendix A as printed.

That said, the very useful `empirical/make_study_flashcards.Rmd` produces a related but distinct artifact — a longer, per-outcome report, with one outcome per page, with `describe_clusterRCT()` stats, DF, and singleton/doubleton counts — useful for cross-checking Appendix A's numbers but not its source.
