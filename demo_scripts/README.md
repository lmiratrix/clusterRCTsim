# demo_scripts/ — Demonstration Scripts

Short, standalone scripts that demonstrate key workflows or concepts in the project. Useful as starting points for new users or for testing that the environment is set up correctly.

## Files

| File | Purpose |
|------|---------|
| `demo_fingerprint_sim.R` | Demonstrates running a fingerprint simulation: loading a real-data fingerprint, generating synthetic data from it, and comparing estimator results. |
| `demo_grid_dgp.R` | Walks through the DGP grid workflow: creating a scenario grid, generating data, and inspecting the output. |
| `run_single_scenario.R` | Shows how to run and inspect a single simulation scenario end-to-end. |
