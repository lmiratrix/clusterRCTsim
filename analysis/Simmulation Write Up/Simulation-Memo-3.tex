Main Bullet Points:

*The estimators theory says are unbiased are indeed consistently
unbiased (or have very low bias across the full range of simulations)

*The LRapw−FIpw−db has bias as large as -.025, which seems from the
statistical model to be driven by the interactions of a large treatment
effect standard deviation across clusters, high variability in cluster
size, and correlations between treatment effect and cluster size. This
is consitent with theory.

*For the various estimators that are biased, the mean bias is mostly
driven by the different blocks being different from each other

Description of Analysis

*The graph is a boxplot of mean bias across the different scenarios by
method. The faint horizontal lines go out to the full range, the bars
are the 1\% to 99\%, and the boxes are the 10\% to 90\%.

*The first table contains the regression coefficients from a regression
that predicts the magnitude of the mean bias using different data
generating parameters. Each regression is run separately by estimator
and mean bias is the mean bias against the targeted estimator.

*The second table contains the DGPs that produce that largest magnitude
of mean bias for each method, conditional on the magnitude of the mean
bias being at least .1 . Where again mean bias is the mean bias against
the targeted estimator.

\subsection{What does the error look like for each
estimator}\label{what-does-the-error-look-like-for-each-estimator}

Main Bullet Points:

*For the person weighted estimators, the unbiased estimator both has
less error and is more stable than the biased estimator.

*For the cluster weighted estimators, the unbiased estimator generally
has less error than the biased estimators but more instablity.

*The MLM estimators are the most stable, which fits with theory.

*High RMSE and estimate instability is driven by a low number of
clusters, the interaction of a low number of clusters and high cluster
level ICC, and high cluster level treatment effect variance.

*Re the question on pg. 39, looking at the second boxplot shows that
true S.E. do vary across estimators with the true standard error in a
given DGP often 40\% bigger for some estimates than the median estimate
in that DPG.

Description of Analysis:

*The first graph is a boxplot of the normalized RMSE across the
different scenarios by method. The normalized RMSE is the RMSE for given
method divided by the median RMSE across methods within a given
simulation scenario. Therefore each data point is adjusted for the
underlying base RMSE from a given set of DGPs and represents the RMSE
driven by the estimation method.

*The second graph is a boxplot of the normalized estimate standard
deviation across the different scenarios by method. This is also
normalized by dividing by the median estimate standard deviation within
a given simulation scenario.

*The first table contains the regression coefficients from a regression
that predicts the RMSE using different data generating parameters and
the second table is from regressions predicting the estimate standard
deviation. Each regression is run separately by estimator and the RMSE
is against the targeted estimator.

*The second table contains the DGPs that produce the normalized RMSE
(against the targeted estimator) for each method, conditional on the
magnitude of the being at least 1.10.

*The third table contains the regression coefficients from a regression
that predicts the true superpopulation estimate standard error using
different data generating parameters.

*The fourth table contains the DGPs that produce the normalized super

\subsection{What do the estimated standard errors look like for each
estimator}\label{what-do-the-estimated-standard-errors-look-like-for-each-estimator}

Main Bullet Points:

*This section answers the rest of the questions from pg.39 (i.e.~are
certain SE estimators more accurate than others)

*For the cluster targeted estimates the unbiased estimators produce more
accurate standard errors than the biased estimators (graph one). The
unbiased estimators produce more unstable estimates than the biased
estimators, but in 90\% of the DGP we looked at they aren't a lot more
unstable (graph four).

*For the person targeted estimates the unbiased estimators produce more
accurate standard errors than the biased estimators (graph one), except
when the school ICC is zero and the blocks are all very dissimilar from
each other and their is high variance in the cluster sizes. if all three
of these risk factors are not present than the unbiased estimator
standard estimates are generally fine (graph two). The unbiased
estimators produce more unstable estimates than the biased estimators
unless all three of these factors are present (graphs four and five).
However they aren't a lot more unstable, 90\% of the time they're within
about 10\% of the median instability.

*This section also answers the question from pg. 38 about the
instability of the estimated standard erros for the fully interacted
models, what I've been calling hte unbiased estimators. The simulations
do not really show that the standard errors from the fully interacted
models are lot more unstable than the other standard errors. We should
talk about this more, and what would be helpful for me to dig into more.

Description of Analysis:

*The first graph is a boxplot of the estimated standard error accuracy
across the different scenarios by method. Standard error accuracy is
quantified as the estimated standard error over the true super
population standard error. Estimated standard errors are most accurate
if the number is close to one. Numbers below one represent under
estimated standard errors and numbers above one represent over estimated
standard errors.

*The second graph is the same as the first but for just the person
weighted fully interacted estimators broken out by identified ``risk
factors'' for poorly estimated standard errors. In the graph on the left
the school level ICC is zero, the blocks are all messy, and there is
high variance in the cluster size and the graph on the right does not
have all three of these things at the same time.

*The third graph is a boxplot of the standard deviation of the estimated
standard error across the different replications by method.

*The forth graph is a boxplot of the normalized standard deviation of
the estimated standard error across the different replications by
method.

*The fifth graph is the same as the fourth graph but broken by the same
risk factors as before.

*The second graph is a boxplot of the normalized estimate standard
deviation across the different scenarios by method. This is also
normalized by dividing by the median estimate standard deviation within
a given simulation scenario.

*The first table contains the regression coefficients from a regression
that predicts the RMSE using different data generating parameters and
the second table is from regressions predicting the estimate standard
deviation. Each regression is run separately by estimator and the RMSE
is against the targeted estimator.

*The second table contains the DGPs that produce the normalized RMSE
(against the targeted estimator) for each method, conditional on the
magnitude of the being at least 1.10.

*The third table contains the regression coefficients from a regression
that predicts the true superpopulation estimate standard error using
different data generating parameters.

*The fourth table contains the DGPs that produce the normalized super
population estimator standard error for each method, conditional on the
magnitude of the being at least 1.10.

\subsection{What do the confidence intervals look like for each
estimator}\label{what-do-the-confidence-intervals-look-like-for-each-estimator}

Main Bullet Points:

*The unbiased estimators also have less error than the biased
estimators. The unbiased person estimator has less instability than the
person estimator, but the unbiased cluster estimator has more
instability.

*The MLM estimators are the most stable, which fits with theory.

*High RMSE and estimate instability is driven by a low number of
clusters, the interaction of a low number of clusters and high cluster
level ICC, and high cluster level treatment effect variance.

Description of Analysis:

*The first graph is a boxplot of the normalized RMSE across the
different scenarios by method. The normalized RMSE is the RMSE for given
method divided by the median RMSE across methods within a given
simulation scenario. Therefore each data point is adjusted for the
underlying base RMSE from a given set of DGPs and represents the RMSE
driven by the estimation method.

*The second graph is a boxplot of the normalized estimate standard
deviation across the different scenarios by method. This is also
normalized by dividing by the median estimate standard deviation within
a given simulation scenario.

*The first table contains the regression coefficients from a regression
that predicts the RMSE using different data generating parameters and
the second table is from regressions predicting the estimate standard
deviation. Each regression is run separately by estimator and the RMSE
is against the targeted estimator.

Coverage is the percentage of simulation replications where the
estimator is within the 95\% confidence interval. We would like the
number to 95\% (the boxplots have a red line at there). The notable
things are that the coverage for the MLM estimators is often very bad
but other than that the coverage for the cluster weighted estimators is
generally good. The coverage rates for the person weighted estimators
however are pretty bad across methods,it's either very low (meaning the
SEs are being underestimated) or too high (meaning the SEs are being
overestimated within the same methods. In addition, finite versus super
makes very little difference for the cluster targeted estimators but
makes a noticeable difference for the person weighted estimators.
